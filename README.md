# Ceiling Grid Simulator

An interactive ceiling grid planning application built with Svelte 5, TypeScript, and Tailwind CSS. Design and visualize ceiling layouts with components like lights, air vents, and smoke detectors on a 1000x1000 grid.

## Tech Stack

Svelte 5, TypeScript, Vite, Tailwind CSS, shadcn-svelte, Lucide Icons

## Getting Started

### Prerequisites

- Node.js 22.11.0+ and npm 10.0.0+

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The app will be available at `http://localhost:5173`
Deployed version at - https://ceiling-editor.onrender.com

## Deployment

### Render.com

1. Node.js version: **22.11.0** (specified in `.node-version`)
2. Build command: `npm install && npm run build`
3. Publish directory: `dist`

### Other Platforms (Vercel, Netlify, etc.)

- Node.js version: **22.11.0+**
- Build command: `npm run build`
- Output directory: `dist`
- Framework: Vite
